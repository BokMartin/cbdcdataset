About the project

We think there's a gap in how CBDC projects get compared — and a dataset was the way to close it.

Why we're doing this

Trackers of central bank digital currencies are useful for one question — how far along is a project? — and mostly silent on the ones we think matter more: what is it for, what is it built on, and how does it treat privacy? We built this dataset to answer those questions from official or authority-attributed documents rather than tracker labels. The current v10.2e workflow uses two independent model providers, source-span verification, explicit ensemble rules and a probability-sampled double-blind human audit.
