Data & reproducibility

Current v10.2e derived outputs for 113 documents, 3,963 page units and 6,949 source-verified union candidates. Public files contain analytical outputs, paired blind human-review data and provenance—not API keys or source PDFs whose redistribution rights are unclear.

Current release — v10.2e

The two sealed provider runs contain 11,358 source-verified statements (OpenAI 5,675; Claude 5,683). Deterministic source-span matching and deduplication produce 6,949 candidates. The primary equal-vote ensemble retains provider disagreements and is accompanied by OpenAI-only, Claude-only and exact-code-consensus variants.

Validation status: calibration precision 0.980, recall 0.766 and span fidelity 1.000; recall failed the frozen threshold. Independent blind coding is complete for 365 candidates and 36 dual-empty units. Reviewer-specific design-weighted validity is 78.6% and 76.1%, inclusion agreement is 62.6% (AC1 = 0.426), and consensus adjudication remains work in progress.

Reproducibility boundary

Deterministic: source verification, canonicalisation, candidate matching, ensemble allocation, scoring, figures and statistical outputs replay from frozen artifacts.

Provider-dependent: the original extraction requires the named model APIs. Raw responses are sealed before parsing so the published run can be audited without rerunning a model.

Human-dependent: the independent blind phase is complete and its reviewer-specific estimates are released. A single final consensus-validity estimate and provider-to-consensus agreement remain unavailable until the 319-case adjudication queue is resolved.
